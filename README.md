# 声间 · Voice Studio

独立的 macOS 本地语音工具：麦克风录音 → 文字识别 / 直接输入文字 → Qwen3-TTS 克隆或 OmniVoice 设计语音 → 扬声器、虚拟麦克风或双路播放。

## 启动

双击 `启动声间.command`，或在此目录运行 `./start.sh`。界面：<http://127.0.0.1:8030>。
启动终端关闭或按 Ctrl+C 后，工具会停止自己启动的语音服务，以及由它启动的 Ollama；复用的已有 Ollama 不会被停止。不会停止露米服务。

- 界面和音频设备控制：8030
- 独立 Qwen3-TTS：8031
- OmniVoice 低音耳语声音设计：8033（首次选用时加载模型）
- 独立 SenseVoice ASR：8032

四个 Python 环境均在本项目中；初次安装可运行 `scripts/setup.sh`。需要 Python 3.12、uv 和 ffmpeg。
工具代码不调用露米的服务，但为了避免重复下载大模型，目前默认读取本机已有模型文件：

- Qwen3：`../VoiceCloneTTS/engines/Qwen3-TTS-12Hz-1.7B-Base-bf16`
- SenseVoice：`../digitalman/resources/models/sensevoice`

可通过 `QWEN_TTS_MODEL`、`SENSEVOICE_MODEL_DIR` 改成独立模型路径；只需要模型文件，不需要启动对应项目。默认使用 1.0 倍原速。模型、Python 虚拟环境、参考录音和生成音频不纳入 Git。新电脑需要自行准备模型，并将参考录音放到 `data/reference/voice.wav`，将对应的准确文本以 UTF-8 保存到 `data/reference/transcript.txt`；也可通过 `QWEN_TTS_REFERENCE` 和 `QWEN_TTS_TRANSCRIPT` 指定其他路径。本机已配置好的文件会保留。

## 使用

1. 直接输入文字，或切到麦克风输入并授权浏览器录音。
2. 麦克风默认开启「自动模式」：点击开始后持续录音，每次说话后静音 2 秒自动提交本句；后续声音进入下一批次。可调人声检测灵敏度。关闭自动模式可手动结束，单次最长 60 秒。识别结果可展开查看。
3. 一次最多 500 字，先选择声音和输出设备。原始克隆音色可边生成边播放；低音耳语设计音色会在整句生成后自动播放。
4. 如需先审听或保存，点击「只生成音频」，完成后可在底部重播或下载。麦克风默认勾选自动转换：每句识别完成后，结果直接合成并播放到所选设备；取消勾选则停在文本编辑。
5. 可随时停止播放或下载 WAV。

这是逐句语音转换，不是低延迟实时变声。自动模式在每句静音 2 秒后提交识别，默认自动合成并播放；勾选虚拟麦克风时也会向该设备输出。

## 虚拟麦克风

macOS 必须安装系统音频驱动才能让其他程序看见虚拟输入。使用官方 BlackHole 2ch：
<https://existential.audio/blackhole/>

双击 `安装虚拟麦克风.command`，安装器会要求本机管理员密码。按安装器提示重启电脑，然后重新启动此工具。

- 本工具：勾选「虚拟麦克风」，输出设备选 BlackHole 2ch。
- 聊天程序：输入麦克风选 BlackHole 2ch。
- 如需同时自己听到声音，再勾选扬声器或耳机。工具分别向两个设备输出，无需改系统默认输出。
- 双路由独立设备时钟播放，可能有少量不同步；不是采样级同步监听。
- 只有播放的克隆语音会进入虚拟设备；本工具不会把原始麦克风音频直通。

官方操作说明：<https://github.com/ExistentialAudio/BlackHole/wiki/Use-BlackHole-as-a-Virtual-Microphone>
驱动未安装或未暴露可用音频设备时，界面会明确禁用虚拟输出。

## 数据与运行

录音仅在识别请求期间处理，不落盘。生成音频仅缓存在当前后端内存中（最多 12 段、约 48 MB 浮点音频），重启后清空。参考录音保存在 `data/reference/`。所有推理在本机进行，首次环境/模型下载需要联网。
界面仅监听回环地址；禁止外部 Origin 请求控制音频设备。不更改系统默认输入输出，也不会自动打开聊天软件发消息。

在浏览器出现麦克风权限提示时，允许本站录音；必要时到 macOS「隐私与安全性 → 麦克风」允许浏览器。

## 验证

```bash
.venv/bin/python -m unittest discover -s tests -v
node --test tests/test_segmentation.cjs
```

覆盖输入校验、外部网页访问限制、设备断开、过期音频与 WAV 返回。

本机验证结果：7 项接口测试通过；参考 WAV 经独立 ASR 接口识别成功；界面文字合成得到约 4.8 秒音频，首次实测约 18 秒；MacBook Pro 扬声器输出成功并正常结束。虚拟设备真实接收测试等待管理员完成 BlackHole 驱动安装。浏览器现场麦克风录音仍需首次授予录音权限。

## 流式播放（2026-10-12）

新增「边生成边播放」：Qwen3-TTS 使用真正的增量解码，每约 0.8 秒语音形成一个 PCM 块；音频设备保持打开，连续接收分块，不等待完整 WAV。保持原 1.7B bf16 模型、参考录音与 1.0 倍速，没有改成量化模型。当前仅原速支持流式。

点击停止会停止设备输出，并在模型产生下一个分块时结束生成。流式完成后仍可下载完整 WAV；取消的半段不保存。服务串行使用同一个模型，避免并行请求干扰解码状态。原有只生成模式保留。

实测同一句「你好，这里是声间。现在使用原始克隆音色。」：首段 0.98 秒，设备开始写入 1.01 秒，完整生成 4.62 秒，音频 4.88 秒；该次无设备欠载。不是跨机器性能保证；首次加载、文本长度、排队和系统负载都会影响速度。流式不能保证总耗时减少，生成跟不上时可能断续，页面会提示改用只生成模式。

10 项测试通过；真实设备流式播放、停止取消及取消后的普通合成恢复均验证成功。虚拟麦克风仍需管理员安装 BlackHole 后才能实测。

### 播放缓冲修正（2026-10-15）

流式播放器默认积累 1.6 秒 PCM 后开始输出，减少每块 0.8 秒音频生成耗时波动导致的欠载。短于阈值的句子在生成结束时立即播放。使用同一个设备流，保留全部采样，不通过拼接淡入淡出掩盖缺音。页面显示实际开始写入设备的时间。增加缓冲会增加首声等待；持续生成慢于实时仍可能断供。

### 实时输出杂音修正（2026-10-15）

用户确认流式保存 WAV 与整句 WAV 均干净，排查重点转向实时设备输出。播放器改用设备原生采样率（本机扬声器及 BlackHole 为 48 kHz）、float32 双声道回调输出。24 kHz 模型 PCM 经 soxr 持续重采样，跨块保留重采样状态；声卡回调仅从缓冲区复制样本，不进行网络、推理或重采样。保留起播缓冲和停止功能。

新增 `device_underflows`（声卡欠载）和 `buffer_starvations`（回调缺少源音频）诊断，便于区分设备调度与模型供给不足。14 项测试通过，包含分块与整段重采样一致、尾部完整、回调跨块顺序及取消。实际扬声器测试：6.72 秒音频，首块 0.93 秒、首次回调音频 2.50 秒，两个断供指标均为 0；用户随后复核确认播放效果正常、杂音问题已解决。以上性能数据为单次运行测量。


## 麦克风自动分句（2026-10-16）

默认自动模式改用浏览器本地 Silero VAD v5 判断人声，不依赖音量阈值：检测到人声、随后停顿约 2 秒便提交当前句；持续监听，后续声音进入下一批。保留约 300 ms 开口前音频，低于 160 ms 的短促触发不提交。每段持续讲话最长约 55 秒，随后继续采集下一批，以适配后端单段 60 秒限制。轻声漏检时选「高」，噪声误触发时选「低」。VAD 能减少环境声误触发，但并不保证在所有麦克风和噪声条件下准确。

VAD 模型、ONNX Runtime Web 与音频工作线程保存在 `web/vendor/vad/`，均从本机 8030 静态服务读取，自动模式运行时不从 CDN 获取资源；初次安装或更新项目时需要取得这些项目文件。麦克风音频在浏览器内检测，只有分出的语音片段会发送给本机 ASR。手动录音方式不变。浏览器麦克风实测仍需在用户的实际设备和权限环境下确认。

识别队列与合成播放队列独立：上一句合成、播放期间持续收音，可继续说话并识别下一句，合成播放按顺序执行；转换流程不会暂停人声检测。最多积压约 12 句，达到上限会明确结束录音并继续处理已提交的句子，避免无限堆积。输出设备与是否自动转换在开始录音时确定。点击「结束自动录音」会提交末尾未满 2 秒静音的句子，队列继续处理；点击播放区「停止」会结束自动录音、丢弃未提交尾音及待处理队列，并停止当前播放。

自动模式佩戴耳机可减少环境回声。浏览器请求回声消除，但本机原生扬声器输出不一定被浏览器回声消除覆盖，持续收音时请使用耳机或仅输出到虚拟麦克风，避免播放的声音再次被收录并触发转换。录音仅驻留内存，不落盘。新模式的分句和排队行为有自动化测试；真实麦克风的阈值和实际听感需要按使用环境试听。


## 本地聊天建议

切换「聊天建议」，聊天记录默认收起且可选。留空直接点击生成，会得到三句打招呼开场白；展开填写记录后，则基于上下文生成三条回复。每条以一行可点击的建议显示；点击即自动合成并播放到当前所选输出（包括勾选的虚拟麦克风），无需再选用、编辑或点击播放。关系和表达意图收在「可选设置」。播放期间禁用候选，防止重复触发；原聊天记录始终留在框内，可直接修改后再生成。清空按钮清除记录和建议。

使用本机 Ollama 的 `qwen3.5:9b`，无需云端 API Key；已安装 Ollama 时启动脚本会复用或启动它。首次准备模型：`ollama pull qwen3.5:9b`。可用 `VOICE_TOOLS_CHAT_MODEL` 指定其他已下载的本地模型。服务只访问 `127.0.0.1:11434`，拒绝 cloud 模型名称以及包含远端托管信息的模型。本工具启动 Ollama 时设置 `OLLAMA_NO_CLOUD=1`。聊天内容只随本次请求在内存处理，不写入历史数据库或浏览器持久存储；不要额外启用 Ollama 请求正文调试日志。

每次最多 6000 字聊天背景、300 字意图。首次模型加载较慢；与 TTS 共用 GPU，建议先选好回复再播放。模型未启动、超时或返回格式错误会明确提示，可以重试，不使用假模板冒充模型结果。

设计参考：[HighEQ](https://github.com/LZJA/high-eq-project) 的背景/意图/多候选流程、[eq-chat-advisor](https://github.com/qihao520/skills/blob/master/eq-chat-advisor/SKILL.md) 的自然口语方向、[人情世故 Skill](https://github.com/IvyYang1999/renqing-shigu-skill) 的关系与表达边界。提示词为本项目独立编写，没有复制第三方代码、私人语料或整套 Skill，也未使用限学术用途的 ESConv 数据。


流式语音完整播放成功后，会将实际播放文本追加为“我：……”并用于下一次聊天建议；包括点击建议、文字流式播放和麦克风自动转换。取消、失败、仅生成未播放不会追加，底部重播不会重复追加。记录只保留在当前页面内存，刷新后清空；超过 6000 字时从最早记录开始省略。点击清空后，清空前已开始的播放也不会重新写回记录。

OmniVoice 克隆和声音设计的本地试听、耗时与用户反馈，见 [OmniVoice 测试记录](docs/omnivoice-clone-test-2026-10-16.md)。声间已接入用户选中的「低音耳语」设计音色；页面顶部可与原始 Qwen3-TTS 克隆音色切换。该设计音色不使用参考录音，整句生成后再自动播放，适用于文字、聊天建议和麦克风识别后的转换，输出仍可同时送往扬声器与虚拟麦克风。首次选用需要加载模型，后续保留在独立的 8033 服务中。模型与相关环境不纳入 Git，新电脑运行 `scripts/setup.sh` 安装依赖并在首次生成时下载权重。

## 自定义声音克隆

右侧「克隆自己的音色」可上传 3–30 秒的单人参考录音（建议 5–15 秒、清晰、无背景音乐），填写音色名称和准确原文。可先点击「自动识别原文」，再试听并校正。点击「保存并使用音色」后，在顶部声音选择器切换到该音色，输入文字合成即可试听克隆效果；麦克风自动转换和聊天建议也会使用当前选择。自动 mic 会话在开始录音时固定音色，队列处理期间不会随选择变化。

这是参考音频驱动的本地 Qwen3-TTS 克隆，无需训练新模型。参考录音统一转为 24 kHz 单声道 PCM WAV，名称、原文与音频存储在 `data/voices/<id>/`，刷新页面和重启服务后保留；该目录不进入 Git。顶部记住上次选择，自定义音色可试听参考录音或删除。原始参考音色和 OmniVoice 低音耳语仍可选择。请使用本人或已获授权的录音。

实现选择参考了本机两个项目的功能：`VoiceCloneTTS` 包含参考音频、原文和音色列表的管理流程，且已验证本机 Qwen3-TTS/MLX 克隆；`digitalman` 侧重数字人对话与消费已有音色。本项目独立实现音色管理，直接扩展现有 Qwen 服务，不依赖这两个项目的运行中服务，也没有复制其应用代码。Qwen 模型文件仍按前文配置复用。

API：`GET /api/voices` 列表、`POST /api/voices` 创建（表单 `name`、`reference_text`、`file`）、`GET /api/voices/{id}/audio` 参考录音、`DELETE /api/voices/{id}` 删除。合成和流式接口的 `voice` 可取 `clone:<id>`；两个接口均将音色 ID 传给 Qwen worker，由服务端解析本地参考录音，浏览器不传入文件系统路径。
