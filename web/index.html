02 选择声音去向

设置虚拟麦克风
  1. 安装 BlackHole 2ch 驱动。官方说明 ↗
  2. 安装后按提示重启电脑，再启动此工具。
  3. 在此勾选「虚拟麦克风」，选择 BlackHole 2ch。
  4. 在聊天程序中，把输入麦克风也选为 BlackHole 2ch。

项目内提供 安装虚拟麦克风.command，双击安装。系统会要求管理员授权。

同时勾选扬声器即可边听边发送，无需改变系统默认声音输出。
