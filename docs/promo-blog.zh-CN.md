# 声间：让想说的话，用喜欢的声音说

写好了一段文案，想听听它读出来是什么感觉；准备了一份录音，想让自己的音色说出新的内容；在语音聊天前，又想先把措辞整理清楚。

这些需求看起来不同，却可以放进同一条流程：准备内容，选择声音，再决定把声音送到哪里。

这就是「声间 · Voice Studio」正在做的事。它是一款面向 macOS、使用本地模型的开源语音工作台，把文字转语音、声音克隆、麦克风逐句转换和聊天建议放在一个界面里。

**输入文字，也可以直接开口说。**

最直接的用法，是输入一段文字，选择音色，然后合成试听。适合给短视频准备一段旁白，为作品录制介绍，或者比较同一句话用不同声音表达的感觉。生成的音频可以重播，也可以下载为 WAV，继续用于自己的创作。

Qwen3-TTS 克隆音色支持边生成边播放，首段音频准备好、经过缓冲后即可开始输出。想先检查完整效果，也可以选择只生成音频，再决定是否播放。

不想打字时，切换到麦克风输入即可。自动模式会检测人声，在说话停顿约两秒后提交当前句，交给本地语音识别，再用选中的音色合成播放。识别和合成播放分别排队，上一句处理时可以继续说下一句。

这个模式适合允许逐句等待的表达场景：先说出内容，再由另一种声音重新表达。它有识别、合成和缓冲所需的时间；需要即时对话时，请把这段等待考虑进去。连续使用建议佩戴耳机，减少播放声音被麦克风再次收录的情况。

**用一小段参考录音，建立自己的音色。**

声间支持上传 3–30 秒的单人参考录音，建议使用 5–15 秒、清晰且没有背景音乐的片段。填写音色名称和对应原文，保存后就能在顶部声音列表中选用。

原文也可以先交给本地模型识别，再试听、核对和修正。保存后的音色能用于文字合成、麦克风转换和聊天建议，刷新页面或重启服务后仍然保留，也支持试听参考录音和删除。

这套克隆流程由本地 Qwen3-TTS 驱动，无需为每个音色单独训练模型。参考录音的清晰度、原文准确度和说话方式都会影响结果，实际效果可以直接通过试听来判断。请使用本人或已获授权的声音。

除了参考录音驱动的克隆音色，声间还接入了 OmniVoice 的「低音耳语」设计音色，方便体验另一种声音风格。该音色在整句生成完成后播放，可以在同一个界面中切换使用。

**声音的去向，也由你选择。**

合成结果可以通过扬声器或耳机播放，也可以送往虚拟麦克风。

在 macOS 安装并配置 BlackHole 后，可以把声间的输出交给其他支持选择音频输入的程序：在声间中选择虚拟设备，再在目标程序中将同一设备设为麦克风。这样，生成的声音就有机会进入语音聊天、直播或录制流程，不必每次都先导出文件再导入。

声间也支持同时输出到耳机和虚拟麦克风，方便自己监听，并把声音交给另一个程序使用。具体接入方式取决于目标程序的音频设置。

**不知道怎么开口时，先看看三种表达。**

「聊天建议」提供了另一种入口。可以填写最近的聊天内容、双方关系，以及这次想表达的意思，让本地模型生成三条候选回复；也可以留空，从几句问候开始。

选中喜欢的一句，就能用当前音色合成并播放。它把“想怎么说”和“用什么声音说”接在一起：措辞由你判断，声音由你选择。

聊天建议通过本机 Ollama 模型运行。对需要先组织语言、再用语音表达的人来说，这是一种可以慢慢斟酌的使用方式。

**把语音工作流留在自己的电脑上。**

声间的语音识别、声音合成和聊天建议均在本机运行，不需要云端推理 API Key。完成依赖和模型准备后，日常推理可以在本地进行；首次安装和下载模型需要联网。

日常麦克风分句录音用于本地识别，处理后不保存为录音文件；主动创建音色时上传的参考录音和原文，则保存在项目本地，供后续合成使用。对于希望自己管理声音素材、愿意动手配置本地模型的人，这样的工作方式更容易掌握数据的去向。

当前版本围绕 macOS 和 Apple Silicon 的本地运行环境构建。首次使用需要安装依赖、准备模型和参考音频，虚拟麦克风还需要额外配置驱动。完成准备后，可以通过启动脚本打开本地网页，把常用的语音操作集中在一个工作台里。

如果你正在寻找一个可以在 Mac 上动手尝试的本地声音工具，不妨从一段文字、一小段自己的录音开始。
